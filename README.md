# Inlämningsuppgift 2 - Praktisk verktygsuppgift

Det här är en övning för att lära oss hantera bash och git och deras olika funktioner.

Vi ska visa att vi behärskar grunderna hur man skapar filer och mappar via Bash.

Det ska också framgå att vi kan hantera Git genom att göra ett repository och använda diverse kommandon.

Kommandon som jag använde var:
## Lists git init
skapar ett repository

## Lists git status
visar vilka filer som ändrats och vad Git känner till

## Lists git add .
la till alla ändringar för alla filer inför nästa commit

## Lists git commit -m "meddelande"
skapar en verision i historiken
